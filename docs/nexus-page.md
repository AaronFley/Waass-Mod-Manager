# 项目介绍（Nexus 页文案）

Nexus 模组页的简介正文。**通篇纯文本，正文里不使用任何标记语法** —— 粘进 Nexus 的 Description 编辑器、GitHub 或任何文本框都保持原样，不会漏出 `[b]` 或 `##`。需要强调时，在 Nexus 编辑器里手动选中按加粗。

Waass Mod Manager

《巫师 3：狂猎》重制版的模组管理器，面向中文玩家：在中文环境下开发，内置同类工具没有的模组汉化功能（语言表、脚本、菜单 XML 三条通道），同时提供完整英文界面，英文玩家同样可用。

9 MB 单文件，双击即用。不需要安装，不需要 .NET，不需要其他模组管理器。

· 它解决什么

巫师 3 里真正决定"谁生效"的是三件事：mods 下的文件夹名、mods.settings 里的优先级、以及脚本有没有被 Script Merger 合并过。多数工具把这三件事当作黑盒，出问题时只能对着游戏日志猜。

Waass 把它们摊开来：哪些模组在生效、谁排在谁前面、哪个函数被两个模组同时改写、哪个菜单文件其实已经失效。改动之前先给清单，改动之后能一步步撤回。

· 功能

启用 / 禁用。禁用即给文件夹名加一个 ~（modHoods 变成 ~modHoods）。游戏引擎只扫描 mod 开头的文件夹，~ 开头的一律看不见 —— 等同于未安装，但文件一个都没少。好处是不必碰格式挑剔的 mods.settings，加载顺序原样保留，随时一步切回。

安装。zip / 7z / rar 等 8 种格式拖入后先看预览：会往游戏目录写哪些文件、哪些会覆盖已有文件，确认后才写入。要往 bin 写 DLL 的包会被单独拦下询问。卸载不真删，文件进入隔离区，随时可取回。

加载顺序。规则只有一条：数字小的先加载，冲突时先加载者生效。列表里直接拖拽，或在加载顺序面板中一次改完。

冲突检查。只检查已启用的模组。脚本层面区分 @wrapMethod（通常可共存，仅提示）与 @replaceMethod（后者会整个替换前者，给出警告）；资源层面只报告界面文件撞车，材质与模型互盖属于常态，不予报告。已被 Script Merger 合并的组会被识别并标绿，不再重复报错。

检查模组更新。不需要 Nexus API Key，不需要登录。程序先从本地证据推断模组在 Nexus 上的 ID（本地记录、安装档案、下载目录中的原始包名、README 链接），无法确认时留空由你选择，绝不猜测 —— 绑错 ID 会让版本比较长期指向别人的模组。

汉化。模组文字可能出现在三处：语言表、脚本内嵌、菜单 XML。程序会指出哪一类仍有未翻译内容，翻译后按等长写回（原文占多少字节，译文不得超过；放不下时明确提示"还差几字节"，绝不截断）。默认只翻菜单页，模组名与物品名保持原样。原始文件永久保留，一键还原。

存档备份。安装模组前自动全量备份一次，之后可自行增量。备份存放在程序的数据目录，不占用游戏目录。

· 它不碰什么

扫描全程只读。写入闸门默认拒绝一切写操作，仅放开四个位置：mods/、dlc/、菜单配置目录、以及 mods.settings 这一个文件。写入前把受影响文件快照到 data/snapshots/；检测到 witcher3.exe 运行中直接拒绝写入；每次写操作都进入撤销栈。

本地服务只监听 127.0.0.1，界面与后台之间使用一次性令牌，并校验 Host 头、拒绝跨站请求。

· 系统要求

Windows 10 / 11（64 位）。巫师 3 重制版 v5.x，Steam / GOG / Epic 均可。界面使用系统自带的 Microsoft Edge 或已安装的 Chrome，无需另装浏览器。

· 快速开始

1. 下载 exe，双击运行。Windows 可能提示"未知发布者"，这是未签名程序的正常提示，选择"更多信息 → 仍要运行"。
2. 程序会从 Steam 库清单、GOG 注册表、Epic 安装清单中查找游戏目录。找不到时请选择包含 bin 与 witcher3.exe 的那一层。
3. 首次扫描会补齐封面与作者，通常不到一分钟。程序内 设置 → 使用说明 有按功能编排的上手指南。

· 一点说明

这个程序不会替你决定装哪些模组，也不会自动"优化"游戏。它做的是把改动摆到台面上：改了什么、改之前长什么样、怎么退回去。

· 许可

MIT。这是一个开源项目，绝大部分代码由 AI 构建。欢迎下载、修改、分享，也欢迎为它做其他语言的本地化 —— 界面文案就是两份 JSON，新增一份即可支持一门新语言。重要问题请在 GitHub 提交 issue，我会持续改进。
