Waass 管的是《巫师3》mods 文件夹里的东西：启停、装包、排序、看冲突、查更新、翻菜单。 它只改你点过的东西 —— 没点的文件一个字节都不动，每次写之前还会先拍快照。

第一次打开

  1. 找游戏目录。程序会自己从 Steam、GOG、Epic 三处找。找不到时主界面会给出引导 —— 选里面同时有 bin 文件夹和 witcher3.exe 的那一层 （不是它下面的 mods，也不是存档目录）。点「浏览」会弹系统的文件夹框； 万一这台电脑打不开选择框（少见），直接把路径粘贴进输入框也一样。
  2. 等它扫完。左边列表是 mods 文件夹里的模组，右边是卡片。 第一次会把封面和作者补齐，几十秒的事，不影响你先用。
  3. 看顶部提示条。金（琥珀）色那一条最多同时说两件事，中间用竖线隔开： 「N 个模组还没对上 Nexus」和「N 个模组有新版本」。两边都有按钮点进去处理。 另有一条橙色的是「N 处需要注意」—— 那才是真出问题的提示。 最上面那条（绿/黄/红）是启动自检：刚换过版本、数据刚升级过、 或者数据读不出来，都会在那里说。

启用 / 禁用

卡片上的开关就是启停。禁用 = 给文件夹名加一个 ~ （modHoods 变成 ~modHoods）。巫师3 只加载 mod 开头的文件夹，~ 开头的它根本看不见 —— 等于没装，但文件一个都没少。

这样做有三个好处：不碰 mods.settings（那文件格式极其挑剔）、 一步就能切回来、加载顺序（Priority）原样保留，禁用再启用之后位置不变。

装新 mod

顶栏「导入压缩包」→ 选 zip / 7z / rar（tar、gz 也认）→ 先看预览：会列出要写进游戏目录的每个文件、 哪些会覆盖已有文件。确认之后才真的写。

写之前自动给 mods.settings 和菜单 xml 拍一份快照，事后能退回去。 游戏正在运行时会直接拒绝 —— 边玩边改会被游戏覆盖，还可能读档异常。

加载顺序

左边「加载顺序」。规矩只有一条：数字越小，优先级越高 —— 这个数字就是 mods.settings 里那个 Priority。

两个 mod 改了同一个文件时，听数字小的那个。数字一样就说不准了， 程序会提示你分开排。「列表视图 + 全部模组 + 按加载顺序」这个组合下可以直接拖拽； 拖拽只会给已启用的模组发号，已禁用的不动。

冲突检查

只查已启用的模组 —— 禁用的模组不参与加载，报它没有意义。

  • @wrapMethod：两个 mod 都想在同一个函数前后插一脚，多数情况能共存 → 只给提示。
  • @replaceMethod：后加载的会把前面的整个函数换掉 → 给警告。
  • 资源包只报界面文件（ui / data）撞车。材质、贴图互相盖是常态，报了只会让人麻木。

Script Merger：两个 mod 改同一个脚本时，靠它合成一份「合订本」。 为重制版新做的模组一般不需要合并，装了很多旧模组、或者启动游戏报脚本错误时才用它。 它装在游戏根目录的 Merger 文件夹里能被自动找到；装在别处，点 「我已装好，指定位置」指一次就行，以后记住。

检查 MOD 更新

要查更新，先得知道每个模组在 Nexus 上是哪一个（那串 ID）。程序只认本地证据： 自己记过的、本程序的安装档案、下载目录里的原包文件名、mod 目录里 readme 写的链接。 宁可空着也不猜 —— 绑错 ID 会让「检查更新」一直拿别人的版本号跟你比。

认不出的模组会摆在「还没对上 Nexus」里，每个下面有「可能是」候选，点一下就绑上。 自制、移植的模组在 Nexus 上根本没有，点「不在 Nexus」就不再提醒。

作者、封面、最新版本这些资料存 7 天，过期才重查。启动时会在后台补一轮，不打断你用。

汉化

模组里的文字有三个地方可能出现：语言表（cn.w3strings）、 脚本里写死的中文、菜单 XML。程序会告诉你哪一类还有英文没翻。

  • 默认只翻菜单页。模组名和物品名不碰 —— 改了容易让游戏里对不上。
  • 按等长写回：原文占多少字节，译文就不能超。放不下会先缩句， 实在放不下会直接告诉你「还差几字节」，绝不截断。
  • 已经手工汉化过的不再烦你：菜单 XML 里已经是中文的模组， 语言表里那些英文算「过期残留」，标一下就过去了。
  • 第一次写入前会把原件存一份，之后任何时候都能一键还原。

存档备份

装 mod 之前，程序会自动把 gamesaves 全量备份一次（只做一次）。 也可以自己点：全量是整包打走，增量只打包自上次备份以来变过的文件，适合每天开机点一下。

还原会覆盖当前存档，所以会再问你一次。备份文件放在程序自己的数据目录里，不占游戏目录。

升级与数据

换新版本只需要做一件事：把新的 Waass.exe 覆盖旧的，双击打开。 模组列表、分组、Nexus ID、安装档案、汉化原件、存档备份全在程序旁边的 data 文件夹里，新版本直接接着用，不需要导出导入、不需要手动搬文件。

每次启动会先自检一遍：这一版是第一次运行、还是刚换过版本；数据格式这一版认不认； 几个记账文件读不读得出来；能不能往数据目录里写。有情况就在界面最上面那条直接说 —— 不用你自己去猜是不是「数据丢了」。

  • 刚换过版本：会明确告诉你「原有数据核对正常（N 个文件都读得出来）」， 或者哪几项有问题、叫什么名字。
  • 数据格式需要升级：升之前先把原来的数据整份复制到 data/_backup/pre-schema…， 之后再动。想退回去，把那里的文件拷回 data 就恢复原样。
  • 数据文件坏了（断电、手改漏括号）：改名叫 xxx.json.broken-日期时间 保留， 绝不删除；程序当作没有这份记录，重新生成一份继续跑。
  • 换回旧版本程序：如果 data 是更新版本的程序写的，程序会切到只读 —— 界面照常能看、能查，但一个字节都不写，免得旧程序读不懂新字段还硬改。 想继续正常用，换回新版本的程序即可。
  • 设置 → 关于里有「数据格式：第几版」和「重新自检」，出问题时这两个信息最有用。

出问题了怎么办

  • 刚做错一步：提示条上有「撤销」，点了就回去。更早的操作在「操作日志」里， 每条都能单独撤销。
  • 改坏了文件：每次写之前都拍了快照（保留最近 30 份），可以整份退回去。
  • 卸错了模组：卸载不真删，文件进隔离区，能捡回来。
  • 想清空间：设置 → 存储与清理。核心数据（配置、Nexus 台账、分组、安装档案、 存档备份、汉化原件）永远不会被清掉。
  • 安装、启用、汉化都失败：多半是权限。Steam 默认把游戏装在 C:\Program Files (x86)\Steam\steamapps\common\The Witcher 3， 这个位置普通权限写不进去。关掉程序，右键 → 「以管理员身份运行」再操作。 程序启动时如果发现游戏目录写不进去，会在顶部黄条先告诉你一声。
  • 换了一台电脑：整个程序文件夹拷过去就能用，数据在程序旁边的 data\ 里。没装游戏的电脑上打开，会提示你选游戏目录，其余功能照常 （模组列表来自你选的那个目录，程序本身不带你原来电脑上的任何数据）。
这一版是 1.3.0。功能和说明不一致时，以界面上的实际行为为准 —— 那是我们的问题，欢迎提 issue。
