Waass 管的是《巫师3》mods 文件夹里的东西：启停、装包、排序、看冲突、查更新、翻菜单。 它只改你点过的东西 —— 没点的文件一个字节都不动，每次写之前还会先拍快照。

第一次打开

  1. 找游戏目录。程序会自己从 Steam、GOG、Epic 三处找。找不到时主界面会给出引导 —— 选到含 bin 文件夹的那一层（不是 mods，也不是存档目录）。
  2. 等它扫完。左边列表是 mods 文件夹里的模组，右边是卡片。 第一次会把封面和作者补齐，几十秒的事，不影响你先用。
  3. 看顶部提示条。金色那条是「有模组能更新」，蓝色那条是「有模组还没对上 Nexus」。 两条都能点进去处理，处理完会自动消失。

启用 / 禁用

卡片上的开关就是启停。禁用 = 给文件夹名加一个 ~ （modHoods 变成 ~modHoods）。巫师3 只加载 mod 开头的文件夹，~ 开头的它根本看不见 —— 等于没装，但文件一个都没少。

这样做有三个好处：不碰 mods.settings（那文件格式极其挑剔）、 一步就能切回来、加载顺序（Priority）原样保留，禁用再启用之后位置不变。

装新 mod

顶栏「导入压缩包」→ 选 zip / 7z / rar → 先看预览：会列出要写进游戏目录的每个文件、 哪些会覆盖已有文件。确认之后才真的写。

写之前自动给 mods.settings 和菜单 xml 拍一份快照，事后能退回去。 游戏正在运行时会直接拒绝 —— 边玩边改会被游戏覆盖，还可能读档异常。

加载顺序

左边「加载顺序」。规矩只有一条：数字小的先加载，先加载的在冲突时赢。

两个 mod 改了同一个脚本文件时，谁排在前面就听谁的。「列表视图 + 全部模组 + 按加载顺序」 这个组合下可以直接拖拽；拖拽只会给已启用的模组发号，已禁用的不动。

冲突检查

只查已启用的模组 —— 禁用的模组不参与加载，报它没有意义。

  • @wrapMethod：两个 mod 都想在同一个函数前后插一脚，多数情况能共存 → 只给提示。
  • @replaceMethod：后加载的会把前面的整个函数换掉 → 给警告。
  • 资源包只报界面文件（ui / data）撞车。材质、贴图互相盖是常态，报了只会让人麻木。

Script Merger：两个 mod 改同一个脚本时，靠它合成一份「合订本」。 为次世代版新做的模组一般不需要合并，装了很多旧模组、或者启动游戏报脚本错误时才用它。 它装在游戏根目录的 Merger 文件夹里能被自动找到；装在别处，点 「我已装好，指定位置」指一次就行，以后记住。

检查 MOD 更新

要查更新，先得知道每个模组在 Nexus 上是哪一个（那串 ID）。程序只认本地证据： 自己记过的、本程序的安装档案、下载目录里的原包文件名、mod 目录里 readme 写的链接。 宁可空着也不猜 —— 绑错 ID 会让「检查更新」一直拿别人的版本号跟你比。

认不出的模组会摆在「还没对上 Nexus」里，每个下面有「可能是」候选，点一下就绑上。 自制、移植的模组在 Nexus 上根本没有，点「不在 Nexus」就不再提醒。

作者、封面、最新版本这些资料存 7 天，过期才重查。启动时会在后台补一轮，不打断你用。

汉化

模组里的文字有三个地方可能出现：语言表（cn.w3strings）、 脚本里写死的中文、菜单 XML。程序会告诉你哪一类还有英文没翻。

  • 默认只翻菜单页。模组名和物品名不碰 —— 改了容易让游戏里对不上。
  • 按等长写回：原文占多少字节，译文就不能超。放不下会先缩句， 实在放不下会直接告诉你「还差几字节」，绝不截断。
  • 已经手工汉化过的不再烦你：菜单 XML 里已经是中文的模组， 语言表里那些英文算「过期残留」，标一下就过去了。
  • 第一次写入前会把原件存一份，之后任何时候都能一键还原。

存档备份

装 mod 之前，程序会自动把 gamesaves 全量备份一次（只做一次）。 也可以自己点：全量是整包打走，增量只打包自上次备份以来变过的文件，适合每天开机点一下。

还原会覆盖当前存档，所以会再问你一次。备份文件放在程序自己的数据目录里，不占游戏目录。

出问题了怎么办

  • 刚做错一步：提示条上有「撤销」，点了就回去。更早的操作在「操作日志」里， 每条都能单独撤销。
  • 改坏了文件：每次写之前都拍了快照（保留最近 30 份），可以整份退回去。
  • 卸错了模组：卸载不真删，文件进隔离区，能捡回来。
  • 想清空间：设置 → 存储与清理。核心数据（配置、Nexus 台账、分组、安装档案、 存档备份、汉化原件）永远不会被清掉。
